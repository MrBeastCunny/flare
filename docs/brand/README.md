# Flare brand

The mark is a four-pointed star: a flare of light. Its points are drawn with sweeping, uneven
curves so it reads as motion rather than a static sparkle.

| Asset | Use |
| --- | --- |
| `flare-mark.svg` | The mark on its own (minimum 16 px) |
| `flare-mark-white.svg` | The mark on crimson or photographic backgrounds |
| `flare-logo.svg` | Mark with wordmark on light backgrounds |
| `flare-logo-dark.svg` | Mark with wordmark on dark backgrounds |
| `flare-mark-512.png`, `flare-mark-1024.png` | Transparent PNGs for slides and documents |
| `flare-app-icon-1024.png` | App store and directory listings (white background) |

Web app icons live in `web/public`: `favicon.svg`, `favicon.ico` (16, 32 and 48 px),
`apple-touch-icon.png` (180 px), `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`,
`site.webmanifest` and `og-image.png` (1200 by 630, social previews).

**Color:** Flare red `#EC0D23` for the mark. Interface crimson `#C8102E` (oklch 53% 0.205 24) for buttons and
links. Wordmark ink `#111111`, or `#FFFFFF` on dark.
**Type:** Inter, weight 650. Never stretch, rotate, recolor, outline or add effects to the mark.
**Clear space:** at least half the mark's height on every side.
